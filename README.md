Um pequeno negócio de salgadinhos artesanais no Rio de Janeiro.

O site foi desenvolvido para apresentar o cardápio, permitir que o cliente monte seu pedido e gerar uma estimativa de orçamento antes de entrar em contato pelo WhatsApp.

**Pedido mínimo:** 50 unidades.

O cliente pode misturar os sabores e escolher quantidades diferentes de cada produto.

## 🛠️ Tecnologias
- HTML5
- CSS
- JavaScript
- WhatsApp Click-to-Chat
